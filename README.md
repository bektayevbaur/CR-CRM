# CR-CRM — Clean Republic CRM

CRM для химчистки обуви **Clean Republic** (Алматы). Одностраничное веб-приложение: весь код в одном файле `index.html`.

## Возможности

- **Заказы** — список с фильтром по статусу (Принят → В работе → Готов → Выдан / Отменён) и поиском по номеру, имени, телефону, бренду и боксу.
- **Приём** — оформление заказа: клиент (поиск по телефону, бонусы), обувь (бренд, подлинность, тип, размер, материал, цвет), до 6 фото, загрязнённость, тариф и доп. услуги, скидка/промокод, выбор свободного бокса, забор и доставка.
- **Карточка заказа** — смена статуса, оплаты (наличные / карта / Kaspi Pay), фото «после», сообщение клиенту в WhatsApp.
- **Наряд-заказ** — печатная форма с условиями, выгрузка в PDF.
- **Клиенты** — база клиентов, история заказов, бонусы.
- **Касса** — выручка, средний чек, долги, разбивка по способам оплаты, точкам, каналам, тарифам и мастерам.
- **Настройки** — прайс, точки, мастера, менеджеры, количество боксов, ставки мастеров, реквизиты и условия наряд-заказа.

## Как работает

Приложение опубликовано как Artifact на claude.ai и использует его встроенные сервисы через `window.claude.use(...)`:

| Сервис      | Для чего                                   |
|-------------|--------------------------------------------|
| `db`        | общая база: `orders`, `clients`, `config/main`, `meta/counter` |
| `assets`    | хранение фото обуви (`/_blob/<id>`)         |
| `user`      | идентификатор сотрудника и права на запись |
| `downloads` | сохранение PDF наряд-заказа                |

Поэтому файл, открытый напрямую в браузере или на GitHub Pages, покажет интерфейс, но **без базы**: сохранять заказы и загружать фото не получится. Рабочая версия — Artifact на claude.ai.

## Обновление

`index.html` в этом репозитории — копия опубликованного артефакта. После изменений в артефакте копию нужно обновить и закоммитить.
